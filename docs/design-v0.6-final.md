# 旅途 v0.6 设计定稿（上一个交付人）

> 本文件是 v0.6 的**权威视觉/交互规范**，优先级高于 spec-v0.6.md。实现时以此为准。

## 3D 地球（替换 2D MapView）
- **镜头**：1.8 个地球半径（太空贴近感）
- **风格**：真实地形轮廓 + 大气层 + 微辉光边缘（混合风）
- **自转**：无操作 12 秒后慢速自转开始
- **星空**：粒子系统，1500 颗，微微闪烁

## 光影
- 用 Three.js DirectionalLight 模拟太阳，实时跟着时间，温和的实时渐变（日出→正午→黄昏→夜空）
- **时间光影方案（优先动态）**
- 顶栏右侧小控件（太阳图标）
- 默认：跟随系统时间连续渐变（分阶段：晨光 / 日间 / 黄昏 / 星辰，不是一天的硬切换）
- 点太阳图标 → 三个预设按钮（自动 / 全日白 / 星辰），可快速预览

## 标点 + 路线
- 蓝色光柱（垂直 3D 小柱子）+ 圆点 + 序号（微微垂直浮动）
- 路线：贝塞尔曲线 + 沿曲线流动的小光点（动画）

## 视觉升级
- 玻璃风（blurred 半透明）+ 蓝青色系
- Framer Motion 动效（入场、hover、弹窗、转场）
- 全套页面重排版

## 封面页
- 远景 3D 地球 + 星空 + 大字标题
- "进入"（或自行优化的文字）大按钮，动效：按钮按下去 → 地球向你飞近撑满屏幕 → 主页从下方滑入
